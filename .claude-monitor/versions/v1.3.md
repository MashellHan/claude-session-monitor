## Changes from v1.2

### Bug Fixes
- **URL extraction in topic-derived project names** — `truncateProjectFromTopic("https://github.com/org/my-repo something")` previously returned `"my-repo someth"` (14-rune truncation applied to the whole string including trailing text). Now correctly extracts only the URL's path segment: `"my-repo"`.
- **CJK rune boundary** — Fixed test expectation for 14-rune CJK truncation to correctly count runes.

- `TestParseAgentJSONLFull` — Single-pass parser: tokens, model, tool calls from fixture data
