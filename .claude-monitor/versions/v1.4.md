# Version 1.4 — Final Polish, Scroll Support & Code Quality

**Date:** 2026-04-15
**Iterations:** 15–20 (of 20)
**Commit:** (pending)

## Changes from v1.3

### Bug Fixes
- **Duplicate project/topic display** — When project name is derived from topic (`ProjectFromTopic=true`), the topic column is now suppressed to avoid showing identical text in both Project and Topic columns. The `~` prefix on the project name already indicates it was derived from the topic.

### UX Improvements
- **Scroll indicators** — Both Sessions and Agents panels now show scroll position when content exceeds the viewport: `↕ 1/15 (scroll 0%)`. Helps users understand there is more content to navigate.
- **Agent table scroll support** — Agent table now respects viewport height with proper scroll offset (was rendering all agents regardless of available space).
- **Session detail: Kind field** — Expanded session detail now shows the session kind (interactive/background/batch) when available.

### Code Quality
- **Deduplicated `extractAssistantText`** — Was an exact copy of `extractTextContent` (28 duplicate lines). Now delegates to `extractTextContent` directly.
- **Removed custom `max()` function** — Was shadowing Go 1.21+ builtin `max()`. Removed since project uses Go 1.26.

### Test Coverage (5 new test functions)
- `TestExtractAssistantText_DelegatesToExtractTextContent` — Verifies deduplication correctness
- `TestTruncateProjectFromTopic_EdgeCases` — URL with no path, trailing slash, exact 14 runes, 15 runes
- `TestFormatTokenCount_Boundaries` — 12 boundary cases (0, 1, 999, 1K, 10K, 1M, 1B, etc.)
- `TestSanitizeOneLine_Complex` — Multiple newlines, CR+LF, whitespace-only strings
- `TestModelShortName_Variants` — Sonnet, haiku, opus variants, unknown models
