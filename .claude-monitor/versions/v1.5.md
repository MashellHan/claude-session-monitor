## Changes from v1.4

### HIGH Fixes

1. **Quadratic `sanitizeOneLine` → O(n)** — Replaced `for strings.Contains("  ") { ReplaceAll }` loop (O(n^2) on long whitespace runs) with `strings.Fields` + `strings.Join` (single pass).

2. **Blocking `listenForFileChanges` → timeout** — Added 30-second timeout to the watcher channel select. Previously, if the watcher stalled or was closed, the Bubble Tea event loop would block forever, killing auto-refresh.

3. **Synchronous `refreshData` → async** — Manual refresh (`r` key) and filter toggle (`f` key) now use `asyncScan()` instead of blocking `refreshData()`. This prevents UI freezes on large `~/.claude/` trees. Dead code `refreshData()` removed.

4. **Dead `hasModel` branch fixed** — `ParseAgentJSONLFull` had model extraction inside `if hasUsage` gate, making it unreachable for lines that have `"model"` but not `"usage"`. Restructured to parse any line that passes the pre-filter, ensuring model detection works for all agent JSONL formats.

### MEDIUM Fixes

5. **Token double-counting guard** — `Stats()` agent-level fallback now explicitly resets counters before accumulating, preventing potential token inflation if the logic changes in the future.

6. **Unreachable code removed** — `go vet` caught stale `return` statement after refactoring refresh handler.
