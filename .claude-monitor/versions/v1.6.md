## Changes from v1.5

### 1. Session Panel Taller (40% → was 30%)
- Session list now gets 40% of terminal height instead of 30%
- On a 50-line terminal: ~18 visible rows (was ~13)
- Agents and tasks share the remaining 60% equally (30% each)

### 2. Visual Separators Between Panels
- Empty line inserted between Sessions ↔ Agents panels
- Empty line inserted between Agents ↔ Tasks panels
- Layout budget accounts for the 2 extra separator lines

### 3. Agent Description Column Wider (max 100 → was 60)
- Description column can now use up to 100 columns
- On wide terminals (160+ cols) this shows much more of the agent description

### 4. Agent Detail Collapse Hint
- Expanded agent detail box now shows `⏎ Enter to collapse` at the bottom
- Makes it clear how to dismiss the detail view
- Agent selection already uses `▸` cursor + yellow highlight on the selected row
